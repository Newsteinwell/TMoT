# v61 冻结TMoT后的类别距离读出诊断

目的：区分当前TMoT劣于FeCAM时，保存的合成点统计近似、学习表示、分类读出三者可能的影响。不是把FeCAM改名成TMoT，也不是本轮正式持续学习算法结果。

固定v54的task256检查点（seed42/order17，三个困难分类集×mantis/summary），不更新网络、不修改缓存、不重采样合成点。检查点和输入hash锁定。比较三个坐标空间：原始512维投影input、已学习隐藏128维hidden、原始+隐藏640维joint。每个空间都按样本L2归一化，使用同一类别条件相关矩阵距离公式与alpha .01/.1/.5/1/2/10网格。

统计来源分为两支：synthetic只读取已保存的合成点，每点权重为该单元真实样本数/点数，类内均值和协方差按原人口计数归一化，协方差使用N-1校正；real_diagnostic读取所有已经到达的TRAIN，通过冻结函数映射后建立真实类别统计，只用于离线诊断，不计入低缓存方法，不称为理论上界。不读取TEST。共6个作业、216组最终阶段诊断，无阶段平均分或遗忘曲线。

原始input+真实统计的六个alpha结果必须与v59 FeCAM逐一预测一致；原TMoT预测必须与v54一致；源检查点、网络与随机状态不改变。每个类别的加权原始二阶矩与独立中心化计算协方差互核。保存所有最终预测、距离、类别均值和核查结果。参数按最终VAL选择，仅描述开发结果，后续改法需从完整任务流重新训练验证。

本次仅诊断分类读出，整体目标仍包括类增长和回归。此前回归强基线与负结果保留，不能由此推出一般优势。
