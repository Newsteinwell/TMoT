追加最后观测即带来明显改善，说明已有表示/投影与读出没有充分保留或利用近期目标信息。残差先验进一步改善北京，但在Air明显不利，说明时间自相关先验需要任务适配。当前实验不能细分信息究竟在编码还是随机投影中损失，也不能直接推导通用选择规则。

带训练残差的stable_residual没有优于北京解析残差ridge：summary最优32.397，Mantis30.812。Air最优约0.890仍弱于此前真实ER约0.827。更复杂的训练读出不是这轮增益的来源，不将北京解析参考的改善误归因于WiMoT全模块。

## 对总目标的影响

这一轮定位了回归预测适配问题，没有证明一般多维时序持续学习的多数优势。分类分支与正式七数据分母保留，新增TEST仍封存。持久性残差仅适用于输入含可观测历史目标的预测场景，不能直接用于任意连续标签回归。完整每条轨迹及失败历史均保留。

下一步v20固定参数检查五个分类集的三类序、五种子，比较高斯矩回放与真实回放。它用于诊断类序敏感性和矩近似误差，不是把失败候选提前推进正式TEST。
