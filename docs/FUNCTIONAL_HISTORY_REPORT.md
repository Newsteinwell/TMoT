stage记录的function_optimizer_steps描述当前函数的拟合步数；首阶段冻结参考后续重复报告同一函数的步数，不能将其逐阶段累加。已到达参考每阶段确实重拟合，才可累加这些值。参数量和函数结构相同不代表训练或存储预算相同。

本实验将“允许继续学表示”的可达结果与“只保存固定函数统计”的结果区分开，不能将差异全部归因于一种因素。下一步应优先在Air summary这类有明确适配空间的场景验证历史风险迁移，再将同一方法完整评估于全部七数据集；不能移除当前没有收益的数据集或将该参考冒充最终算法。
