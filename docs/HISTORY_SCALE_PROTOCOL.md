# v42：已有开发数据上的历史规模检查

v41修复了最终读出的数值失稳，但没有形成多数数据集优势。本轮不增加模块或调参维度，回到此前已经使用的HAR、UWave、DailySports、Energy开发集合：HAR训练5867、DailySports5700，显著大于4MiB真实特征重放容量；UWave96和Energy390作为小样本对照。所有数据仍为固定Mantis缓存、原有TRAIN/VAL划分、类序17、种子42，不读取TEST，不修改正式七数据集分母，不把这些结果称为新的盲测。

状态审计重建原坐标真实TRAIN矩，检查各ridge与对应控制具有相同函数和补全矩、local/ER训练步数和历史代表数量相同、首阶段预测相同、ER缓冲区容量、独立读出复算与VAL指标。参考包含此前v7同六点ridge基线与v11等更新数非线性ER结果；历史参考的HPO预算/模型不同，标明比较口径，不伪称完全匹配。
