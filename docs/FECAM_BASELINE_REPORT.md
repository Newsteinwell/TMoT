# FeCAM 时序分类读出基线

官方代码固定版本及适配差异见third_party/fecam/PROVENANCE.md。96条VAL筛查完成，指标/输入哈希审计通过；数值测试与官方预训练分类头公式一致。输入为与其他读出相同的固定512维时序基底，不能将结果解释为原论文图像实验复现。

每个数据/表示在预先固定的6个alpha1中选择VAL最高值；单类序、确定性读出，不是多种子泛化结果。

FeCAM在当前表示下未整体超过已有线性/真实回放强基线，但仍纳入完整基线比较，不删除其强弱结果。该方法只承担分类对照，回归沿用其适用的统计读出/真实回放基线。正式报告还需等存储字节预算、更多类序/训练种子及最终锁定测试，当前不能据此认定TMoT目标完成。

原始方法来源：[FeCAM论文](https://arxiv.org/abs/2309.14062)，[官方代码](https://github.com/dipamgoswami/FeCAM)。
