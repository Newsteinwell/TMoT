# v49：固定非线性函数的真实历史矩读出诊断

v48 的协方差结构变化未产生整体优势。本轮固定 v48 的全部 48 个最终函数、输入基底、类序与标签缩放，仅以到达过的全部真实 TRAIN 样本重新计算联合非线性 Gram 和特征—目标矩。沿用相同六点 ridge 和正则创新读出，得到 288 个最终阶段诊断。先验证原始 512 维块与旧精确矩一致，再用显式残差特征正规方程独立复算读出。

使用分类类别平衡风险与回归样本平均风险。对照原模型预测、真实 TRAIN 风险和近似矩风险；保存每种配置的最终 VAL 预测、读出、样本 ID 和目标。TEST 不读取。所有变体分别报告固定 ridge 差值及各自六点网格结果；不得合并 4 个变体搜索后宣称等预算胜出。

这是假设可以访问全部历史 TRAIN 的诊断，不能作为有界存储持续学习算法的有效结果，也不是数学性能上界。只检查最终阶段，不报告或推断阶段平均性能。若精确矩读出仍弱，则当前学习函数/表示或读出本身仍有瓶颈；若精确矩明显更好，支持研究非线性矩估计，但不能单凭此诊断证明某种具体替代算法有效。

六数据集、两表示、四协方差变体与 v48 完全相同。12 个 CPU 进程，各一个数值线程。此操作不重新训练函数，无需以 GPU 利用率衡量效率。正式十数据集验收与普遍增益目标不变。

执行修正：初次诊断按整个 VAL 一次变换，Air Quality 两组合与旧分组批次的浮点计算顺序不同，导致 2.9e-10/2.2e-9 的 RMSE 校验差异。保留初始全部输出；修正版按原任务组执行表示变换和读出乘法，并增加旧预测逐元素精确核验，全部 12 组重跑到独立目录 exact_readout_v49_retry。不放宽容差。
