# v53 已学习特征匹配合成回放

v52 随机特征匹配目标下降但没有整体优势。本轮将 128 维随机线性/ReLU 特征替换为当前到达阶段已经训练完成的 128 维网络隐藏特征；使用其已有全局隐藏归一化。网络参数冻结，只对合成输入（回归包含联合目标）求梯度。仍匹配特征均值与Gram、0.1倍坐标均值/二阶矩，回归额外匹配原坐标—目标交叉矩；隐藏—目标交叉矩包含在联合特征Gram中。

四分支：Gaussian、finite、random（v52 matched的精确控制）、task。均保持每分量16代表、初始化、Adam lr=.05/80步、回放配额与网络训练一致；两种匹配目标维数相同但梯度计算成本不同，报告时间，不声称FLOP严格相等。旧分量不重新优化。只用当前到达TRAIN，不保存真实历史行，拟合后解除teacher引用；不保存历阶段网络。分量数仍随到达增长。

为提供已训练网络，基类新增默认update_local钩子，默认行为仍直接local.update；新子类只在该调用期间设置teacher。测试旧采样与训练精确控制及teacher释放，运行后gaussian/finite/random逐阶段复现v52对应分支。六数据集、两表示、四分支、六ridge：48次共享训练/288条VAL轨迹，20并发，TEST不读。

这是单种子开发实验。每分支独立同六点选择，完整报告所有数据与阶段平均。正式十数据集验收和类新增/回归双路线保持不变，不能以某个局部成功取代普遍稳健优势。
