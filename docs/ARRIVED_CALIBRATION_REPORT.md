与first相比，arrived的局部矩方法10个数据流最终指标为1胜/3平/6负。HAR三个类序最终宏准确率变化分别−0.539、−0.067、+0.189个百分点；DailySports分别−0.351、−0.877、−0.439个百分点；UWave三个类序均不变；Energy最终RMSE由63.716升至64.865，虽阶段平均RMSE改善0.188，也不足以支持最终指标收益。ER对应10个流为3胜/3平/4负。20对总体4胜/6平/10负，不能混合分类百分点与回归RMSE计算总体数值增益。

结果反对“仅累计更新函数输入标准化即可获得普遍改善”的实现假设，不证明任何校准策略都无效，也不能证明类序影响与首阶段表示无关。改变标准化还改变网络训练条件；这里没有重新搜索ridge，结论只适用于预登记的固定参数隔离对照。本轮seed42，并非完整多种子验收。所有原结果保留，TEST未评分。

决定：不将arrived升级为默认，也不在新数据上把这一额外选择计为隐性搜索。新增三数据集首轮使用已登记的first校准，与累计ridge和ER公平六点网格比较。后续重点依据更高类别数与小样本流的失败模式检查表示/风险近似，而不继续扩大这一单独改动的运行次数以寻找最好种子。
