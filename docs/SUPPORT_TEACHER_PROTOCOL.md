# v75 历史输入覆盖对照

教师与v74一致：FeCAM alpha10或累计ridge0.1。固定蒸馏强度10，原开发6数据×2表示×current/local/er10，共36条轨迹，seed42/order17。当前真实标签仅用于当前任务监督损失，历史输入只接受教师约束，避免把生成标签误差混入覆盖诊断。

每阶段所有方法均使用当前N条输入加4096条支持输入，30epochs、batch256、同网络与初始化、相同更新步数。current支持输入为当前样本有放回重采样；local为到达时存储的低秩局部矩生成历史输入；er10为每个历史任务最多floor(N/10)的真实缓存重采样。ER缓存零容量时显式回退当前输入，不补借配额。首阶段三者都是相同当前重采样。历史池在本阶段训练完成后才加入当前任务。局部矩秩16、4分量、最小单元4、回归保留XY/YY矩，复用已有实现。

当前监督权重归一化为1（分类平衡当前类、回归样本均匀），支持输入监督权重为零。教师约束权重一半当前、一半支持。每种损失分别归一化，所有模式相同；小批次通过全局权重计算无偏加权损失。首任务输入校准只用原始当前样本，不用重采样支持。每阶段固定抽样种子1701+stage，便于复算支持SHA。类别顺序继承旧头，新类别仅由当前标签扩展。支持行的占位标签不参与监督损失。

所有原始样本回放严格遵守用户每历史任务10%上限，记录实际选择索引；生成样本数量不等于真实缓存量。三者支持存储字节不同，记录而不称相同内存。更新步数相同，但局部生成/教师距离计算等额外开销仍不同。

必须核验首阶段三者逐值一致、全阶段教师预测精确复现v74、支持输入哈希重算、真实缓存配额与选择索引、各阶段指标与最终检查点。不存全部支持数组以节省磁盘；支持可从到达TRAIN与确定性存储/抽样重建。无TEST，不将开发结果当盲测，不将教师蒸馏改善等同于TMoT整体超过强基线。
