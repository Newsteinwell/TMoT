# v39 保留原坐标精确矩的条件补全

固定126条VAL轨迹：九组数据/表示×局部统计/ER×六点ridge补全版本，加18条ridge=0.1关闭补全控制。函数训练、抽样和权重沿用v38；新增精确原坐标矩存储。全部七数据集、分类和回归、此前强参考保持，TEST不读取。

令φ=[x,1]为原512维坐标的齐次表示，h为新增128维函数。保存真实到达数据的G₀=E[φφᵀ]、K₀=E[φyᵀ]、V₀=E[yyᵀ]。分类按类平衡；回归按样本量加权。V₀分类为I/C，回归由真实目标矩得到。

代表分布给出A=E[φφᵀ]、U=E[φhᵀ]。估计B=A⁺U，新增函数残差协方差Rₕ=E[hhᵀ]−UᵀA⁺U及残差交叉矩C=E[hyᵀ]−UᵀA⁺E[φyᵀ]。真实目标残差矩Rᵧ=V₀−K₀ᵀG₀⁺K₀。对称矩做谱分解处理舍入误差，并将白化C的奇异值截断至1，得到与Rₕ、Rᵧ兼容的交叉矩Ĉ。

补全E[φhᵀ]=G₀B，E[hhᵀ]=BᵀG₀B+Rₕ，E[hyᵀ]=BᵀK₀+Ĉ；原G₀、K₀、V₀直接保留。联合矩按条件模型构造为半正定，实际浮点实现记录最小/最大特征值，并检查相对容差。它是兼容的近似联合矩，不是真实非线性历史矩的精确恢复。

函数和生成分布不读取补全读出，因此补全开关不应改变函数网络、训练步数和重放数。关闭控制须精确复现v38。所有补全版本须保留原输入/目标块，检查联合PSD及独立读出复算，并报告新增存储成本，不能称为等总内存比较。
