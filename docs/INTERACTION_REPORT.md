## 解释边界

所有方法使用相同的新输入；回归Beijing保留相同因果残差参考，Air使用none。交互块包含通道自身时间相关和跨通道项，本轮不能将变化归因于某一项。额外64维增加了模型容量和统计内存，不能称为等维或等内存对照。

原表示对照训练时逐阶段匹配v54/v68 task、v60/v68 ridge、v59 FeCAM。复核从共享状态重建所有最终预测；所有阶段指标重算，样本ID/标签/输入哈希检查通过。新表示的统计只由首任务训练数据决定，样本内归一化不跨样本。

整体优势须同时超过原表示和新表示的强基线，不将不同编码器算作独立数据集，也不将超参数配置作为独立统计重复。当前开发选择仍需后续多种子验证。
