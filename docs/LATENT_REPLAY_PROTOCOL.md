# v47：相同一二阶矩、不同潜变量分布的统计回放

v35证明历史非线性梯度估计存在系统偏差；v44累计输入校准未普遍改善；v46取消投影只部分有效。检查当前LocalCell后发现其采样是低秩高斯因子加独立对角高斯残差。新假设：在固定局部分区和协方差近似下，无界高斯潜变量的高阶分布可能是可干预因素。本轮仅检验这一因素，不声称它是已确定的根因。

## 单一干预

高斯控制保持原实现；新变体将同一批标准正态潜变量逐元素取符号，成为独立、等概率±1的Rademacher潜变量。两种分布均均值0、协方差I，因此生成分布的期望均值和协方差严格相同，回归共享的X/Y因子也保持原有期望XY/YY矩。有限样本经验矩并非逐次相同。新分布的高阶矩和尾部不同，并具有有限支持；它仍可能偏离真实数据流形，回归目标也会更离散，不保证更好。

保留同一normal RNG调用数量和顺序，再取符号，保证后续类别/分量分配使用同一随机序列。聚类、计数、均值、低秩因子、对角残差、支持和最小簇大小均不变；不增加存储数组。分类与回归统一应用。首阶段没有历史回放，预测必须精确一致。

## 固定实验与公平性

数据：PhonemeSpectra、LSST、Handwriting、Energy、Beijing PM2.5、Air Quality；表示：Mantis/summary；局部回放两种潜变量；每种六点ridge .001/.01/.1/1/10/100，共144条VAL轨迹。另补Energy summary同流程ER六条，共150条；其余11组ER六点网格引用已有v45/v41/v42，同步报告累计ridge及更强历史参考，不能只与高斯局部对比。seed42/order17，512维固定基底、128维学习函数、30epochs、4096历史代表、原坐标矩补全和正则化创新读出不变。TEST不读取，正式十数据集验收不变，全部结果保留。

已有11组高斯局部控制共66条应复现：3新分类×2表示来自v45，Beijing/Air×2表示来自v41，Energy Mantis来自v42。Energy summary无对应历史完整控制，依靠原实现等价测试及独立状态核验。

## 共享训练而非重复计算

此前六个ridge配置的函数训练、分区和风险矩与ridge无关，仅最终读出不同；本轮用单一ridge=.1载体训练，每阶段针对同一G/K计算六个读出。分类/回归单元测试须证明与六个独立实例的训练结果一致。25个独立共享状态组、150条读出轨迹；12组并发，每进程1数值线程。训练成本按共享组报告，不虚报150次独立训练。

每组保存一个完整状态，每个轨迹仅保存相应读出及共享状态相对路径和SHA256，所有逐阶段预测单独保存。这样节省重复网络/矩/基底检查点空间，不删除任何指标证据。审计必须解析并验证共享状态引用，不能把小readout文件当成完整模型。

预先检查：150条指标与覆盖，66条旧控制；两种潜变量的所有局部矩数组和生成分配/权重质量一致、首阶段预测相同；每个最终读出及保存预测可重放。报告所有12组各自同六点选择结果和固定ridge配对，不以同一数据的两种表示充当两个独立数据集。单次VAL结果不等同于多数数据集稳健优势。
