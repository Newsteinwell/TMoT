# v51 匹配局部分量配额的真实历史训练诊断

v48—v50 排除了简单提高协方差精度/更换矩来源/联合 ridge 即可普遍解决差距。本轮只改变训练代表样本来源：原局部 Gaussian 与同一局部分量内均匀有放回真实样本。

两分支保持分区、类别/分量配额、主 RNG 状态、固定基底、第一阶段归一化、初始化、网络、30 epochs、4096 回放数、风险质量与优化步数一致。真实分支先消耗原 Gaussian RNG，再使用独立每分量随机流抽取真实联合 XY 行。回归不能独立打乱 X 和 Y。两分支都保存真实分量行以便审计，因此存储无界；这不是候选有界记忆算法或可报告的公平优势。Gaussian 控制应精确复现 v48 rank16/shrink0.1。

六数据集（PhonemeSpectra、LSST、Handwriting、Energy、Beijing、Air）×两表示×两来源，共24次训练、144条六点ridge完整轨迹；20并发、每进程一数值线程。以相同正则创新读出评估完整 VAL 轨迹，再对两个来源各自训练的最终函数用真实 TRAIN 矩重算最终读出，隔离函数学习差异。后者不产生阶段平均结论。TEST不读取，正式验收集合不变。全量保留结果，不按数据集人工选择来源。
