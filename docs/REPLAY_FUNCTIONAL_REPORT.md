## 风险近似与存储

本轮不再是固定函数的精确累计风险：历史新函数矩来自生成代表。当前实现将整个640维矩在代表集上重建，连原512维坐标的历史G/K也被重新估计；因此既可能损失非线性函数信息，也会丢失此前能够精确保留的线性二次风险信息。这是代码结构可确认的设计差异，但当前结果不能独立量化两者各自造成多少性能差距。

下一项方法改进应优先保留原固定坐标的精确G/K，仅对新增函数与原坐标的关系及残差统计做近似，并验证所构造风险矩的半正定性和分类/回归目标一致性。这样可以检验性能损失是否来自不必要地重估原有统计，而不是继续单独扩大同一生成分布的样本量。

记录的持久数组/参数字节估计不含公共编码器、Python对象开销或进程RSS，也不是统一总内存预算。PenDigits统计版本约5.20MB、ER约7.92MB；Air summary统计约3.95MB、ER约3.88MB。统计方法并非在所有数据集都更省存储，不能因没有显式样本缓冲区而直接宣称内存优势或隐私保证。
