# v36 首阶段监督函数与精确累计风险

固定108条VAL轨迹：七个Mantis数据集加两个回归summary表示，共九组×随机/首阶段监督函数×六点ridge网格（0.001至100）。种子42、类序17，旧512维表示保留并追加128维两层ReLU特征，最终640维。两种版本同结构、同初始化；训练版本只用首阶段到达数据训练30epochs，分类交叉熵、回归MSE，随后移除训练头并冻结特征网络。随机版本不做梯度更新。

后续到达只更新固定特征空间的分类/回归二阶矩及解析岭读出，新增类别自然扩展目标列，无真实特征回放、无生成式回放。二次风险精确性仅针对该固定函数空间，不等于网络可继续任意训练而保持风险精确，更不保证泛化收益。首阶段监督可能偏向初始类别或初始回归域，是本轮需要检验的局限。

首阶段输入标准化固定；追加隐藏特征以首阶段均值和全局RMS标定，旧512维坐标不变。随机与训练特征使用同一ridge选择预算，所有选择仅用开发VAL；实际参数、维度和矩存储大于原512维控制，不声称等总内存。旧最强参考与七数据集分母保持，TEST不读取。

审计首次拟合之外不可再拟合、网络参数冻结、同版本六个ridge配置共享相同函数、累计矩对完整已到达训练数据重算一致、解析读出与预测指标正确。记录首阶段函数训练步数，不能把精确风险本身当作性能优势。
