# v48：秩截断与对角收缩的二因素对照

上一轮同均值/协方差的两种潜变量各有胜负；探索性检查发现保存协方差有7.82%—24.63%的风险加权方差在局部经验中心化样本空间之外。本轮预登记检验协方差结构，保持高斯潜变量不变。经验空间外方差未被证明有害，零空间外方差也不保证泛化更好。

四个变体：rank16/shrink0.1（旧控制）、rank16/shrink0、full/shrink0.1、full/shrink0。full保留完整中心化SVD因子，不保存样本左奇异向量或原始历史行；shrink0取消收缩。rank16仍用对角残差补足被截断的逐坐标方差。full/shrink0不将浮点相减残差再变成对角噪声，其协方差应等于局部经验协方差至存储精度。分类收缩作用于输入协方差；回归保留原有XY/YY因子，收缩仅作用于不能由目标解释的X残差。所有变体保持局部均值、计数、逐坐标方差及回归XY/YY，不声称保持完整XX矩相同。

## 采样及内存

主RNG仍消耗旧rank16因子宽度和原对角残差对应的高斯抽样，确保类别/分量分配与旧控制一致。若完整因子更宽，额外列用每分量独立辅助RNG；两种full收缩配置共用对应辅助流。辅助种子由分量创建序号确定。所有变体保持相同主RNG状态，不能把宽度变化引起的分配变化混入对照。

完整协方差可能增加因子存储与分解成本，实际记录统计数组字节、保存状态大小和运行时间。数组统计不含Python/RNG对象开销；不声称严格总内存等预算或隐私保证。仅存统计因子也不等于保证不能恢复任何历史信息。

## 固定矩阵

PhonemeSpectra、LSST、Handwriting、Energy、Beijing PM2.5、Air Quality×Mantis/summary×4变体×六点ridge，共288条VAL读出轨迹，48个共享训练状态。seed42/order17，固定512基底、128学习函数、30epochs、4096历史代表及现有读出/矩补全不变。72条旧控制应逐阶段精确复现v47高斯；ER与累计ridge沿用同数据/表示的完整既有网格。TEST不评分，正式十数据集集合不变。

20组并发、各1数值线程，匹配25 vCPU和96GB GPU；每共享组仅训练一次函数，复用六个读出求解，耗时不虚报为六次独立训练。启动前要求至少12GiB空闲，保留所有预测与结果，不覆盖既有队列。

## 核验与决策

测试经验协方差重建、完整无收缩样本的经验空间约束、边缘方差与回归XY/YY、旧采样/训练精确控制。运行后核对288条覆盖/指标/共享状态，72条旧控制，全部144条full配置轨迹及各变体之间的分区、主RNG、优化步数、回放量和质量一致；完整无收缩协方差需对真实TRAIN分区独立重建。报告四变体各自同六点选择、固定ridge二因素差，以及内存/时间。不得合并四种变体后与只搜索一次的ER宣称公平胜出；新候选若有改善，再冻结配置做多种子确认。
