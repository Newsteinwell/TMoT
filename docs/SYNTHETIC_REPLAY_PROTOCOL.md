# v52 非线性统计匹配合成代表

v51 匹配分量配额的真实回放改善部分组合，说明训练分布值得改进。本轮每局部分量使用 16 个合成联合 XY 代表，与连续 Gaussian 和不优化的相同有限代表作对照。分类按类拟合 X，回归联合优化 XY，不能打乱配对。

初始化取原局部 Gaussian 的独立固定随机流。仅在当前到达 TRAIN 分量上标准化，匹配 64 个固定随机线性投影及其 ReLU 的均值/Gram，加上 0.1 倍原始坐标均值/二阶矩损失；回归增加全部坐标与目标的交叉矩损失。Adam lr=.05，80步，保存 TRAIN 匹配损失最优迭代。各损失块用均方平均，不根据 VAL 调权。投影/偏置、真实行与优化器在拟合后丢弃，只存合成代表及原统计量。

三组保持类别/分量配额、主 RNG、网络和训练预算一致。finite/matched 的代表抽样随机流一致，内存数组字节相同；matched 有额外优化成本，必须报告。Gaussian 不额外保存代表。分量数量仍随到达增长，不能声称固定总内存；合成代表不构成隐私保证。这个候选不保留真实历史行。

六数据集×两表示×三来源=36次共享训练，六点ridge=216条完整VAL轨迹，20并发。旧Gaussian必须精确复现v48。检查匹配损失、代表形状/数量、内存、配额和独立读出。所有结果保留；不得选最好来源后声称等搜索预算优势。TEST与十数据集正式验收不变。
