# v38 历史统计驱动的函数适配

固定108条VAL轨迹：九组数据/表示（全部七个Mantis加两个回归summary）×局部统计/4MiB真实特征参考×六点ridge网格。种子42、类序17、30epochs、宽128×2层、每批256、历史4096代表样本。两种方法同模型、相同损失和更新步数；分类交叉熵、回归MSE。12路并发，TEST不读取。

到达时先从旧记忆抽取历史代表，再与当前真实数据一起重新拟合函数，随后在同一代表集上重建640维岭风险矩。局部统计采用K4/support4/min4、回归目标协方差保护；只用当前数据更新历史统计。ER采用4MiB特征/目标/key载荷的key-reservoir参考。局部统计不保留真实特征缓冲区，但统计存储随到达增长，不声称等总内存或隐私保证。

历史代表必须按真实历史质量加权，不能把4096个人工样本当成4096个新增观测。分类每类等质量，同一类历史/当前按实际计数分配；回归历史/当前按已见样本数分配。同一权重用于函数训练、隐藏特征标定和读出矩。输入标准化只保留首阶段均值/标准差，不保存首阶段真实样本；后续隐藏标定依赖当前加权代表集，因此与v37首阶段真实样本标定不同。

旧512维表示固定，追加128维函数会变化。历史新函数矩来自重放近似，不再声称精确风险传输。当前样本贡献直接计算。保存最终加权G/K及读出、函数和历史统计；不保存生成的代表集。记录每阶段历史/当前权重质量、训练步数、重放数和模型字节。

同阶段、同ridge的两种模式首阶段应精确一致。审计局部统计仅含已到达计数、无真实缓冲区、输入标准化不变、加权质量合规、读出复算以及全部预测指标。v37全历史参考和此前最强基线继续报告，不能因设置变化把弱对照当作成功标准。
