## 对原因的约束

Mantis的完整坐标为1542—11308维，512投影确实压缩了维数。LSST与Air的结果支持存在可利用的投影损失，但PhonemeSpectra未改善，说明单纯取消投影不足以解决该数据的差距。与v45的ER比较，完整线性读出仍不能自动在全部新增数据上占优；回归还必须面对已有持久性/因果残差及summary非线性参考。

summary分类完整坐标只有102、204、374维，小于512；原随机映射在这些场景中并不是单纯降维，可能保留全部输入秩却改变正则化度量。因此summary结果不能解释成“找回被压缩的信息”。这里还保持了随机映射的期望分支能量，但没有保持逐样本距离和各方向正则化完全相同。

这一轮排除了求解实现变更作为主要解释：36条分类512控制逐阶段预测精确复现v45；30条回归512控制与已有v7/v9一致，最大预测差2.198×10⁻⁹。结果更支持同时存在表示/正则化设计和非线性历史风险近似的问题，而非一个全局维度参数即可修复。后续需要把对照移到相同的更强表示，并分别检验非线性判别结构与历史风险近似；不因为某个诊断胜出就省略强基线或更改验收集合。
