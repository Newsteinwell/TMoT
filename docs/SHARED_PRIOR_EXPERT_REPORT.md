## 验证集上限核对

已声明强基线在Epilepsy和Articulary的VAL上达到100%，PenDigits达到99.767%；这三个VAL集合不可能再提升1个百分点。只有NATOPS与RacketSports仍有相应空间，详见validation_headroom_audit.json。

这是开发VAL的上限，不代表未查看的TEST上限。正式七数据分母及验收标准保持不变；不能用“验证集已满分”解释回归或其他分类上的实际失败，也不能删除强基线制造增益。后续需结合不同种子/类序、遗忘和平均阶段指标评估稳定性，不能将单次VAL加分作为唯一推进依据。
