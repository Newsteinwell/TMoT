## 决策结论

分类存在互补但并非无代价。Phoneme+Mantis硬目标相对选参FeCAM纠错5.430pp、破坏8.446pp；LSST+summary锐化纠错7.935pp、破坏10.592pp。不能把纠错量或oracle当成可实现收益。Handwriting+summary三种目标均无纠错，即使利用真实标签在两套硬预测中选择，也不能超过参照；这排除了在该配置继续优化两套硬标签选择器的理由，但不排除改变表示或分数融合产生新预测。

固定回归混合在旧开发Energy+Mantis上有局部收益：学生权重0.75时最终RMSE64.046，低于warm ER10的69.692。但Energy不属于新增的正式回归验收集，不能用这一结果替代Air/Beijing证据；还须比较已有更强方法和相同总资源。

Air+summary相对warm ER10最优单权重oracle为0.8033，对照0.8073，仅约0.50%改善；预先固定0.25权重为0.8047。Air+Mantis对应oracle约1.13%改善。Beijing+Mantis相对因果ridge的oracle选学生权重0，即无改善；Beijing+summary仅约0.18%。在当前这些固定预测上，即使标签oracle也达不到5%门槛，说明继续搜索单一凸组合权重不能解决正式回归验收差距。该判断仅针对当前预测的单权重凸组合，不外推任意非线性融合。

因此不将固定混合升级为默认TMoT。下一步将学习分支直接建立在更强的稳定/因果统计预测之上，检验剩余误差是否存在可学习结构，并区分新增有效信息与对弱教师的重复拟合。分类保留强读出，同时需要验证可靠互补信息的来源，不能用VAL标签拟合oracle门控。总体目标仍未完成。
