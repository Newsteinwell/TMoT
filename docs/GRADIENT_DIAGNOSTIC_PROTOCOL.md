# v35 固定模型的风险梯度诊断

36个v31最终模型：九组数据/表示×MSE/任务损失×高斯/ER暖启动模型。在各自固定模型上对全部已到达训练数据计算真实经验风险梯度，再与经验抽样、已存ER缓冲区、单高斯、K4/support4/min4局部统计比较。每种抽样4096/16384样本、各5个固定随机种子，共1440组比较。全部七数据集保留；8路GPU并发。

分类使用全已见类别宏平均风险，回归使用样本平均风险；包括原训练残差惩罚，梯度只对残差网络参数计算。解析读出、标准化、网络参数固定。报告完整经验梯度范数、余弦、相对误差、损失差及沿负近似梯度移动的真实风险一阶方向导数。参考梯度近零时明确标记，不用不稳定余弦作强结论。

完整经验风险使用两种批量分块重算梯度并核对；高斯缓存采样器需与原采样器相同种子逐元素一致；梯度核对有限差分。每个作业检查模型参数和源检查点散列未变、训练缓存散列与原训练记录一致。真实特征仅用于离线诊断，不增加统计量模型的运行时信息。

这是最终固定模型上、全部已到达训练记录的诊断，不是各阶段更新之前的旧任务风险。分类按抽样中类频数重加权，和训练中当前/历史混合的分布也不完全相同。不能用本实验声称已经证明完整训练轨迹的因果机制，也不能把梯度更接近当成VAL/TEST性能优势。两种模型锚点都报告，避免单一模型来源偏差。

不读取VAL或TEST，不更新模型，无新检查点。失败保留并定位，不静默替换作业。
