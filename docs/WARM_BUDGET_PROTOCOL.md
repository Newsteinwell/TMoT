# ER10 跨任务延续网络诊断 v58

基于 v57 固定六数据集、mantis/summary、seed42/order17、30 epochs/阶段、4096历史重放条数、每任务floor(N/10)缓存额度。分类任务内分层无放回选样及独立随机种子不变；空历史缓存不补取原始数据。只使用 TRAIN/VAL，不访问 TEST。

两种变体：warm_er10 不保存累计矩，warm_moment_er10 保存累计矩。每阶段继承上一阶段两层128宽网络参数和监督输出头；分类输出列按类别首次出现顺序扩展，已有类别输出权重/偏置原样拷贝，新增列使用固定种子初始化。回归直接继承输出头。输入标准化沿用第一阶段，隐藏特征标准化仍按当前训练代表加权计算。AdamW优化器状态每阶段重置，学习率.001，权重衰减1e-4。并非所有标准ER设计的穷尽比较。

每组共享函数训练，评估六个ridge值.001/.01/.1/1/10/100及神经网络监督头（工件名r0，表示无ridge而非零正则拟合）。前者用于对照v57读出，后者提供端到端监督预测。带矩统计版本的监督头并不使用矩统计，因此必须与普通版本逐阶段完全一致；缓存选择及函数网络也必须一致。

共24次训练、168条验证轨迹，最多12并发。预先报告按最终VAL选择的ridge及独立监督头结果；不得从多个读出中择优后称为预先固定强基线，不把单种子开发结果当作稳健胜出。对照v57应验证选样索引完全一致以及第一阶段对应读出预测完全一致。分类扩展、零额度任务和回归需测试。
