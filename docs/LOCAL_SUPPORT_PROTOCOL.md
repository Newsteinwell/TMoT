# v33 局部成分支持阈值

固定72条VAL轨迹：九组数据/表示（七个Mantis加两个回归summary）×MSE/任务损失×支持阈值4/16×重置/暖启动。K上限固定4，其余沿用v32；全部七数据集、强参考和不利结果保留，TEST不读取。训练前提交代码，16路GPU并发。

支持阈值只决定请求的聚类数min(4,max(1,n//support))，不是实际每个簇的最小样本数保证。聚类可能产生不平衡簇或少于请求的簇，因此审计必须记录实际成分数与最小簇大小。小簇包括单样本簇时可退化为近似原型记忆，不把所有存储一概称为隐私保护或非样本记忆。

阈值16的36条轨迹应逐阶段精确复现v32 K4对应控制。新旧阈值保持输入、类序、训练步数、4096历史样本预算、解析捷径与目标损失一致；统计存储量允许变化并明确记录，不声称等内存比较。暖启动函数误差继续记录。

本轮检验实际增加小数据集局部成分是否有用，不把增加成分当作预先成立的改进。单种子/类序的VAL开发结果不能替代最终稳健性验证。
