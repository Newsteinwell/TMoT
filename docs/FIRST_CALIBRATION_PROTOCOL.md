# v72 首任务内部时间留出初始化

预先固定首任务TRAIN前80%（向下取整）训练辅助专家、后20%做内部校准。输入窗口按原时间顺序，检查原始窗口边界不重叠。所有辅助basis、参考缩放、目标均值/标准差和模型只拟合前段；不使用外层VAL/TEST。三个先验、TMoT/ridge同等处理，固定seed42与六ridge网格。

内部留出仅提供选择器初始误差；实际预测仍使用已在全部当前任务TRAIN上训练的v70生产专家，并保持其完整轨迹不变。辅助模型与全数据重拟合模型可能有差异，不能声称是生产模型真实泛化误差。此实验会增加首任务三个辅助模型的训练成本。

内部误差拟加入v71累计TRAIN训练前SSE，之后使用相同硬选择。两数据×两表示×两方法×六ridge=48轨迹；分支选择不访问VAL标签。Air首任务21样本仅16拟合/5校准，北京160样本128拟合/32校准，样本少导致排序不可靠是必须保留的限制。先核验校准来源、无标签泄漏和预测，再执行规则重放；不因结果不利改变留出比例。

这不构成独立盲测，也不是通用框架完成证据；类增长分类、无历史目标的连续回归与全部强基线仍在总体范围内。
