# v81：跨通道滞后交互表示

## Material Passport

- 状态：运行前固定；代码实验。
- 来源：v79/v80残差训练收益未稳定泛化的结果；当前特征和读出实现。
- 范围：既有TRAIN/VAL开发划分，TEST不读取；不作盲测或多种子确认声明。

问题：固定表示中增加显式跨通道时间交互后，学习分支是否比同输入强解析读出
获得更稳定的收益？此前弱于基线不能仅靠增加训练轮数或更换初始化解决。

输入块：每条序列每通道独立去均值并按时间标准差归一化，计算滞后0、1、4步的
所有有序通道对乘积均值（包括自身）。不跨样本估计，不使用标签或未来窗口。
在首任务TRAIN上估计共享RMS和均值，用种子2718固定随机投影到64维，
使新块每坐标RMS量级与原512维基一致；随后统计冻结。原512维不变。
该块同时包含通道自相关和跨通道项，本轮不能将收益专门归因于某一种交互。

数据：Handwriting、LSST、PhonemeSpectra类新增；Air Quality、Beijing PM2.5回归。
各用Mantis和summary，两种表示（base/interaction），20个共享训练。
分类每组task-synthetic、ridge各6个原有ridge参数，FeCAM使用原6个alpha；
回归每组task-synthetic和ridge各6参数，共312条轨迹。10路并发。
Beijing固定使用已验证的persistence residual参考，Air固定none；两方法同输入。
task-synthetic保持原256代表点/单元、30epochs、种子42和任务顺序17。
没有新增真样本缓存；统计/合成支持内存单独记录，不声称与ER等内存。

base控制逐阶段精确匹配v54/v68 task、v60/v68 ridge、v59 FeCAM预测。
比较表示改进前后同方法，以及新表示下task对强基线的差距；保留全部参数结果。
原表示强基线仍参与整体评价，不能用变差的新表示基线抬高方法相对收益。

最终模型按20组共享保存，不为每个读出复制大模型；预计新增数GiB，启动需至少8GiB空闲。
验证样本局部性、时间方向敏感性、常值通道有限性、原表示精确复现、首任务冻结；
完成后复核所有阶段指标、输入哈希和最终状态。此轮为表示机制开发，不改变总体验收门槛。
