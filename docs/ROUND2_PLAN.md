## 已发现的实现差异与待验证假设
1. 原型256→64维适配器与256维统计基线不同；信息损失可能影响效果，尚未证明因果。
2. 原型当前CE+SupCon与历史平方损失尺度、目标不一致；训练head和推理ridge也不同。
3. 原型用随机ReLU基础表示，缺少WiMoT第一阶段监督语义分支、固定幅值分支、PCA捷径。
4. 未迁移OSCL方向优化、谱解码、均值方向先验、Student-t训练内校准。
5. 原版按域存储且每域全类别；CIL需要稀疏类别支持，不能伪造未见类别统计。
6. 回归样本很少，简单常数预测强；需评估方差、正则化和训练/历史风险权重。

## 解释约束
- 256维方阵适配器若可逆，并不会扩大线性读出的函数集合；岭惩罚在坐标变换下会改变，因此256维优于64维不能直接证明“更强表示学习”。需要进一步区分秩损失与隐式正则化。
- 训练head与解析head比较应读取同一训练终态；当前两个运行仅推理选项不同且训练过程不依赖该选项，因此应验证训练状态一致。
- 小样本UWave第一阶段样本数不足256，PCA只能采用数值秩截断并补零，不能伪称256个有效方向。
- 持续训练中首阶段监督表示可能偏向初始类别；PCA捷径作为独立消融，不能因最后测试分数好而取消。
