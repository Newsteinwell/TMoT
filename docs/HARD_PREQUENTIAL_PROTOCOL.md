# v71 同一训练前误差下的硬选择

预先固定：第一任务无训练前损失，三专家等权；之后选累计TRAIN训练前平方误差最小的单个专家。同误差按固定none/append/residual顺序选择。与v70使用完全相同的专家、数据、ridge配置、训练前预测及VAL专家预测，无额外训练、不用VAL标签选择专家。

两数据×两表示×两方法×六ridge=48条完整轨迹。仅以已核验v70预测重放固定规则，不能声称新增独立样本或新随机种子。报告全部配置并与软加权、等权及最佳已知单专家对比。TMoT与ridge同等拥有三个专家，硬选择不节省专家维护成本。

独立从当前TRAIN身份和预测重算累计SSE；用独立标量最小值规则核验选择，重算混合预测和各阶段RMSE，验证所有源文件SHA前后不变。固定规则本身是标准选择思路，不冒称原创；目标是区分软混合与误差信号的问题，而非仅增加模块。一般分类/回归范围不缩减。
