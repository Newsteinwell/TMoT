# v32 局部统计与持续表示

固定72条VAL轨迹：七个数据集的Mantis表示，加两个回归集的summary；MSE/任务损失 × K=1/4局部成分上限 × 重置/保留残差表示。其余设置沿用v31：岭参数、0.1残差惩罚、种子42、类序17、30epochs、4096历史重放样本、每批256、16路GPU并发。TEST不读取。

使用已有局部统计实现，不新称为提出了混合高斯：每次到达按类或回归域拟合局部分布，保存均值、rank16因子及对角残差。成分数实际受每组样本数约束，不保证达到4；统计内存随到达增长，不声称固定预算。回归启用目标协方差保护，保留分量内XY和YY；仍不保证有限重放样本精确匹配，更不保证非线性风险精确。

暖/冷成对比较隔离保留表示效果；K1/K4比较局部性，但它们和v31全协方差高斯的差异同时包含低秩近似、局部性及回归目标保护，不能当作单因素归因。v31的单高斯和真实重放参考全部保留。

审计全部指标、缓存散列、配对累计矩/解析读出、训练步数/历史样本数、局部统计一致性、首阶段预测及暖启动函数误差。完整保留不利结果。单种子、单类序开发实验不作为最终稳健优势证据。

启动前整理v17/v18已结束的实验检查点，只删除每组最终/平均指标均未选中的模型；保留配置、来源提交、SHA256清单、预测和指标。被删模型需按清单重跑恢复，旧审计报告是清理前的证据，不能声称当前仍可直接重新加载全部旧检查点。
