# ER 历史样本预算（2026-10-24 用户确认）

每个历史任务 i 的实样本缓存上限为 floor(N_i / 10)，其中 N_i 为训练/验证拆分后真正进入该任务训练的样本数。训练任务 t 时仅允许从之前任务的缓存重放；任务 t 完成后再按额度选入缓存。总上限为已完成任务各自额度之和，不能跨任务借用额度。小于 10 个样本的任务额度为 0，不能用至少一个样本的规则超额。

此前 ER4/ER64 按字节容量做全局随机缓存，没有执行这个比例限制。原有结果全部保留，标识为大缓存诊断；不能当作新预算下的 ER 结果。实测清单见 results/er_sample_budget_audit.json；表中的最终容量包含最终任务完成后写入的缓存，最后一阶段训练时只能访问此前任务缓存。

缓存的是投影特征及标签，不是原始时序，但每条仍按一个真实样本计数。4096 是每阶段有放回抽取的重放训练条数，不是持久缓存样本数。现有 RegularizedInnovationLearner 的 ER 变体还保留原始特征的累计矩，因此应明确称为带矩统计的 ER 对照，并单独核算统计量、网络和缓存总字节，不能称为只有 10% 样本的普通 ER。

后续实现和验证必须覆盖任务级额度、无重复入库、历史零额度及缺失类别处理、训练前后缓存边界，以及最终和逐阶段缓存审计。新预算在 task_budget_replay.py 独立策略中启用，旧字节缓存模式保持可复现；禁止将旧结果重新标注为 ER-10%。应分别报告普通 ER-10% 和用于控制其他模块的带矩统计 ER-10%，并明确合成代表点与矩统计的内存成本。

## v57 预先固定的开发实验

六数据集 PhonemeSpectra、LSST、Handwriting、Energy、Beijing PM2.5、Air Quality，两种表示 mantis/summary，seed42/order17；普通特征 ER10 与带累计矩统计的 ER10 各共享六个读出 ridge（.001/.01/.1/1/10/100），24 次训练、144 条验证轨迹。不访问 TEST，不声称新的盲测。普通 ER 使用标准 ridge；带矩统计 ER 使用现有 regularized innovation，与 v54 task256 的主流水线一致。

分类任务在本任务内按随机类别顺序轮流选样，每类内部无放回，严格总额 floor(N/10)；回归在本任务内均匀无放回。采样随机流与训练重放随机流分离。某些类别无代表样本时不补取历史数据，函数学习风险条件化到实际可表示类别；零历史缓存时只训练当前任务。所有已见类别仍保留输出列，以统一评估遗忘。带矩统计版本仍可通过历史累计统计支持缺失类别；普通 ER 没有这项信息。

报告两种 ER 相对现有 task256 的开发集结果，不因降低 ER 样本预算就宣布方法达到普遍优势。合成点个数和统计量字节另报；两种 ER 的网络训练均为每阶段30轮，非零历史缓存有放回采样4096条，缓存为空时不能伪造这4096条。因此小任务的优化步数可能不同，必须保留实际步数。
