## 核查与限制

3项新增测试通过，覆盖精确输入块、半正定性、无正则情况下的恒等重建、Cholesky/FeCAM逆矩阵一致性、连续任务时不修改训练状态。144条轨迹指标和最终预测核查通过；36条base轨迹逐阶段复现FeCAM。独立直接残差样本重构校正协方差，最大相对误差7.5e-14。

各作业还逐阶段复现原TMoT预测，最终网络参数、g/k、合成点和主RNG与v54完全一致。新增单位化输入矩从当前任务逐步累计，最终与直接TRAIN统计核对；原始检查点通过SHA引用，避免重复保存。

本模块增加每类单位化输入二阶矩，内存随类别数增长，不是固定总内存方法。表中持久数组含同一TMoT训练流水线及新统计、对应头矩统计，不是独立FeCAM最小内存，也不包含临时工作区/Python对象。

这是单种子单顺序的开发实验；不能将条件间事后最优头拼成统一方法，也不能以个别数据集收益声称普遍优势。本轮为分类模块实验，回归目标和已有强基线保留，仍需在后续回归任务验证任何通用改法。

## 结论与下一步

校正版仅在PhonemeSpectra+Mantis上超过已有最强解析基线：最终36.802%对FeCAM35.596%（+1.207个百分点），阶段平均51.343%对51.073%（+0.270个百分点）。其余五个数据集×表示组合均未超过相应强解析基线，不能接受为普遍优势方案，也不更换默认方法。

同alpha成对对照中，统计校正对LSST+Mantis最终结果反而下降约2.03个百分点；因此“保留精确输入统计”本身不足以保证整个联合读出更准确。附加几何检查发现complete有63/158个类别的隐藏二阶范数超过1；LSST+Mantis最大约3.43，LSST+summary约2.69。这说明条件线性校正可以产生与单位化隐藏特征不相容的矩，虽仍为半正定且数值求解正确。不能将这类统计解释偏差误报为数值bug，也不能据此断言它解释全部性能损失。

下一步优先检验不改变输入统计的单位球矩约束，对照未约束版本；同时冻结本轮有增益的配置做跨种子/顺序验证。保留全部六个条件及回归强基线，不把研究缩到单一有利数据集。归一化向量属于单位球，约束应针对收缩前的统计矩，不应把用于数值稳定的alpha正则化误算成真实分布矩。
