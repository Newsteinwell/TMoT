# v66 相对距离间隔选择诊断

固定v64全部36个最终模型与原参数，比较FeCAM和bounded类别条件头。对于一个样本，令d1<=d2为该头最小的两个类别距离，置信代理为(d2-d1)/(d2+d1)，分母0时取0。仅当bounded的该值严格大于FeCAM时使用bounded预测，否则使用FeCAM。无可调阈值，不使用该样本标签，不训练门控，不按数据集另选规则。

此指标只是启发式置信代理，不是校准概率。乘法缩放不改变它；不同头的间隔仍可能不可比较。先做最终阶段低成本诊断，不声称已完成整个持续任务流。报告全部6种数据集/表示、全部种子与顺序，原seed42/order17控制单列。旧模型与统计SHA不变，两个原头预测须精确复现v64。保存距离、预测、选择标志及样本身份，便于独立重算。不得将v65的标签oracle当作可实现结果。

本轮不使用TEST；开发数据已被多轮诊断，不能将本轮称为独立盲测。若无稳定纠错收益则不扩大该规则；若有收益仍需完整任务流与独立评估。回归不能套用类别间隔，须独立研究条件预测可靠性。总体目标仍是一般多维时间序列持续学习，而非单个分类条件有效。
