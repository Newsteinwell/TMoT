# v62 原始表示归一化统计校正：完整类增长轨迹

固定三个困难分类集×mantis/summary，seed42/order17、原TRAIN/VAL划分和原TMoT task256训练流程。每任务仅使用当前TRAIN；额外累计unit(phi)的类均值和二阶矩，不保存历史真实样本。不访问TEST。

每次任务到达后使用当前学习函数重新映射已保存的合成点。使用分块归一化坐标[unit(phi),unit(hidden)]；这与v61整体L2归一化joint不同，故不直接把两个joint数字当成同一处理。各合成点权重为单元原样本数/256，按实际类样本数N以及N-1计算均值/协方差。

对每个类，近似协方差写成[[A,U],[U^T,H]]，固定rho=.01，B=(A+rho*trace(A)/d I)^-1 U（尺度下限1e-12）。残差协方差R=PSD(H-B^TU-U^TB+B^TAB)。将输入块替换成精确累计E，重建[[E,EB],[B^TE,B^TEB+R]]；隐藏均值改为mu_h+(mu_exact-mu_approx)^T B，输入均值精确保留。该条件线性近似不保证恢复真实非线性统计，必须实验验证。

四种头base/approx/self/complete均走完整任务流：base仅使用精确unit(phi)统计（应复现FeCAM）；approx使用原合成分块统计；self仅做同样投影但仍代回原合成输入统计；complete使用上述校正。六值alpha .01/.1/.5/1/2/10，6共享训练、144完整验证轨迹。网络训练不依赖新读出，不额外读取历史TRAIN。旧TMoT逐阶段预测与最终网络、g/k、合成点必须保持完全一致；base六alpha逐阶段复现v59。

为提高计算效率，正定收缩后的相关矩阵使用Cholesky求逆，测试其与FeCAM伪逆一致，实际base预测还需逐阶段完全一致。存储只新增单位化输入矩统计和原训练状态引用，避免复制大型原检查点；其他最终统计可由它们重建。

各头按最终VAL选alpha，同时报告阶段平均指标。base路径仍执行同一网络训练，所以其记录的系统内存不是独立FeCAM最小内存。新增统计必须计入TMoT内存。当前是分类模块实验，回归结果与更强基线继续保留，总目标仍为一般多维时序持续学习；不得把分类收益外推到回归。

正则化投影并非精确条件分解：rho>0时U-AB不为零，本构造舍弃输入与残差的相关项，因此即使E=A也会收缩联合统计。self对照专门隔离这项效应；complete必须与同一alpha的self比较，不能把对approx的全部变化归因于精确输入统计。测试验证rho=0且A满秩时可恢复原联合统计，rho=.01时则验证精确输入块与半正定性。
