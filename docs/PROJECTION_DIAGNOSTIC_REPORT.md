增加宽度不产生一致改善。RacketSports增加3.571个百分点，但NATOPS减少5.556个百分点，北京RMSE恶化；PenDigits仅增加0.070个百分点，Air最终几乎持平。两个已满分分类集继续满分，不能据此声称全面改进。

持久学习器状态随宽度近似平方增长：例如Articulary从512维约50.52MiB增至1024维201.03MiB；该统计不含冻结编码器、基底矩阵和运行时内存，不能当作全部系统成本。

不同宽度随机矩阵不嵌套，差异混合了容量和随机投影实现；因此只能否定“加宽普遍有益”的简单解释，不能证明编码器本身没有瓶颈。后续v23固定本轮参数，以五个投影种子复核全部七个数据，保留负结果。

这轮是表示诊断，ridge的单数据改善不是TMoT核心模块贡献，也未满足多数数据集稳健优势。正式TEST保持封存。
