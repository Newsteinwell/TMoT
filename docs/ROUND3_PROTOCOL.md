# 第三轮：多数数据集明确增益与整体稳健性

## 用户确认的目标
用户选择“多数数据集有明确增益，整体优势稳健”，并继续要求一般多维时间序列持续学习主题，包含类别增长和回归。本轮不以单数据集最好数字或GPU使用率作为成功标准。

## 固定验收口径（在新测试集读取前）
- 主要新验证集合：NATOPS、Epilepsy、RacketSports、PenDigits、ArticularyWordRecognition（分类），Beijing PM2.5、Air Quality（回归）。7个官方归档已下载，维度、样本和划分核验已完成，任何不可用数据的替换必须在读取结果前记录原因。
- 原HAR/UWave/DailySports/Energy保留为开发与回归检查集，不能被称为新的盲测证据。
- “明确增益”工作阈值：相对同数据集最强的预先声明强基线，分类最终宏准确率至少+1个百分点，回归最终RMSE至少降低5%；平均阶段指标也不得反向显著恶化。
- 多数：7个新数据集至少4个达到阈值，其中分类至少3个、回归至少1个；两个任务族的整体方向均为改善。若实际来源核验导致集合变化，在任何测试前重新锁定分母。
- 稳健性：每个分类集5种子×3类序；回归5种子固定时间顺序。报告均值、运行间离散度、逐序配对差值、数据集层面效果。共享测试样本的运行不当作独立数据集；不以简单运行级t检验充当跨数据泛化证据。
- 此标准是可检验的研发目标，不预先保证达成。任何失败场景保留，不删去弱数据来改变“多数”的分母。

## 方法改进候选（先在开发val淘汰，不看新test）
1. 稳定语义残差：保留不受首阶段类别监督截断的固定语义方向，避免只有初始类别子空间。
2. 保留强统计读出：在稳定分支基础上增加可学习残差，而非用低维适配完全替代强基底；回归和分类分别使用相容损失。
3. 用历史输入-目标矩约束残差；比较零残差、无历史项、无稳定分支，验证收益来源。
4. 自适应正则化只在训练内部或统一val预算选择；所有强基线享有同等预算。方法不能通过更大的网格或未来标签获得优势。

## 基线与公平性
保留同表示累计ridge、SLDA（分类）、ER及原TMoT迁移版；回归加训练均值/持久性预测。记录基底训练、记忆字节、训练时间、推理时间；目前仍未实现统一固定字节预算，报告必须保留该限制，后续需要配套字节预算实验。
冻结Mantis是否预训练见过这些数据无法从当前信息确认；任何数据预训练重叠需明确披露，并加入非预训练表示对照，不能称新数据test为对编码器完全未见。

## 已实现候选 stable_residual 与开发筛选
冻结语义部分采用首阶段单一RMS缩放加固定线性投影，幅值部分单独校准；避免少量初始类别的逐坐标方差和监督PCA丢失其他方向。总512维（448语义+64幅值），每一任务都保留累计解析ridge预测，再增加rank64分数修正。修正每次从零开始，以当前监督损失、旧数据精确二次风险和修正范数约束优化；alpha=0严格退化为同基底ridge，已有数值测试。
该设计保留完整稳定分支，但不预先保证适配改善；旧风险仍是平方误差代理，当前分类为CE，是否有效需要实验。
开发矩阵stable_development_v7：仅原4数据集val、类序17、种子42/43；候选与同基底ridge各自同6个岭系数0.001/0.01/0.1/1/10/100；另外no_hist固定0.1、ER全512维、分类SLDA，共118条，16并发。30 epochs，残差范数系数0.1。先据开发结果淘汰该候选，不读取任何新增test成绩。

## v7开发证据与v8下一候选（仍不看新test）
118条v7已完成，候选未胜过同表示ridge：各自6点val最优，HAR93.98对96.22，UWave75.00对91.67，DailySports85.35对96.93；Energy RMSE68.51对64.98。保留结果并淘汰该低秩分数残差候选。
原因推断：线性稳定分支+仿射残差没有扩大线性读出函数集合，当前CE/平方损失修正可损害解析解；不能靠继续扩大epoch保证优势。
v8改为保留256维线性分支，并拼接固定两尺度随机傅里叶特征512维（共768维），在该固定非线性基底存矩。用已到达样本的聚合矩计算在线均值/方差仿射变换，再精确传输历史矩并解析拟合读出；对照为同基底静态ridge。长度尺度固定，不逐数据集搜索。
4个开发数据集×2模式×6岭系数=48条，seed42、order17；作为成本较低的筛选，尚不构成稳健性证明。纯矩阵解析拟合使用CPU，12进程×2线程匹配25核配额，不为提高GPU显示利用率做无效运算。新函数非线性来自固定输入映射，矩传输仍是仿射且历史二次风险精确。

## v10：非线性残差与近似历史矩回放（开发机制筛选）
依据v7-v9负结果，新候选保留512维固定基底的精确累计ridge分支，添加512→128→128→输出的ReLU残差网络。每阶段从零输出残差重新训练；使用当前真实样本及历史生成样本。分类存每类均值/协方差，回归存每次到达的输入-目标联合矩；高斯协方差向对角收缩0.1并进行PSD截断。回归保留到达批次混合分布，按样本数采样；分类均衡采样已见类别。禁止未来类别/目标参与。

这里仅基础ridge风险是精确的，非线性历史风险通过高斯近似；二阶矩不能唯一确定非线性风险，不能沿用WiMoT线性传输的精确性宣称。矩生成样本为临时训练数据，训练后不持久保存。回归联合矩随到达次数增长，分类矩随类别数增长，当前不声称固定字节记忆。

预先固定56条：旧HAR/UWave/DailySports/Energy×2训练种子×(高斯矩回放、真实样本回放各3个残差惩罚0.01/0.1/1 + 无历史残差回放0.1)。首阶段固定基底seed1701、类序17、ridge0.1、30epochs、AdamW lr0.001、batch256；MSE目标，分类one-hot、回归连续值。分类按类加权，回归按真实历史/当前样本数加权。高斯最多4096个历史生成样本；真实回放4MiB优先级蓄水池、每阶段至多4096条。两种回放同架构、同超参预算；但记忆字节尚不等价，实际字节逐阶段记录，正式实验仍需统一字节预算。无历史仅去掉非线性分支历史训练，累计ridge历史仍保留。

alpha=0回退测试、联合分布矩采样测试、类增长/回放字节测试必须通过。运行仅旧数据VAL，不读新增TEST；本轮目的是判断非线性容量是否带来真实收益，以及矩近似相对真实回放的损失。不因结果不佳追加未记录的网格。

v10执行：56条全部完成并通过指标/输入哈希审计。高斯残差各3点最优的两种子均值：HAR96.890%、UWave95.833%、DailySports96.404%、Energy RMSE68.474。只有UWave相对此前最优线性基线表现出较大开发改善；其他集合尚未形成普遍优势。

## v11：对齐更新次数，并使用共同的已选基础配置
检查发现v10虽然epoch相同，但ER缓冲区最多约2000条且无放回取样，而高斯回放4096条，所以实际更新步数不等。v10保留为探索证据，不将其称为严格等计算预算比较。
v11让ER从已存缓冲区有放回补齐至4096个历史训练样本，Gaussian也为4096；相同网络、batch256、30epochs、每阶段当前样本均相同，逐阶段记录实际optimizer_steps并核验配对相等。独立数据多样性仍不同，真实缓冲区字节限制仍4MiB，且矩记忆字节不同，不能据此声称等存储预算。
共同基础ridge系数由已经完成的v7线性基线VAL选择：HAR1、UWave0.1（与1并列，取较小者）、DailySports0.1、Energy1。两种残差都使用这些相同配置，再分别使用同3个残差惩罚0.01/0.1/1；原4开发数据×2种子×2回放×3惩罚=48条。仍只使用旧VAL，不开启新TEST。本轮包含前轮开发选择，不能作为未调参泛化证明。
23项测试通过，包括实际回放数量/梯度更新次数相等测试。配对审计进一步检查基础读出/基底完全一致、验证ID与标签及阶段覆盖一致。

## 相关方法边界（2026-10-24核对原始论文）
生成特征回放已有明确先例：Liu等的[Generative Feature Replay（CVPR2020 workshop）](https://arxiv.org/abs/2004.09199)将生成回放用于分类器；[FeCAM（NeurIPS2023）](https://arxiv.org/abs/2309.14062)直接利用类协方差的各向异性距离；[AdaGauss（NeurIPS2024）](https://arxiv.org/abs/2409.18265)研究增量适配中的协方差变化与维度坍缩。因此v10/v11的高斯伪回放本身不能作为原创贡献。当前它是诊断非线性历史约束的模块候选；正式论文需补充分布/协方差类强基线，并证明跨分类与回归的具体新机制、适用条件及增益。当前没有完成这些证明，不能以改名或跨数据迁移代替方法创新。

v11全部48条完成，指标/输入哈希审计通过；24对Gaussian/ER的基底、基础读出逐元素相等，每阶段更新次数及历史训练数量相等，验证集ID/标签和阶段覆盖全部一致。初步改善主要仍在UWave，不能称多数数据集明显优势。

## v13：补齐协方差分类基线
FeCAM官方仓库固定到e33f39d112ff2d2a2df2e68c490af579a50edd31，MIT许可保存在third_party/fecam。按官方预训练ViT分类头流程实现：样本L2归一化、每类无偏协方差、alpha1对角加载（alpha2固定0）、协方差转相关矩阵、伪逆Mahalanobis距离；不用Tukey变换。仅将输入替换为与其他读出相同的固定512维时序基底。零方差/单样本保护、重复到达类别的可合并矩、缓存伪逆属于工程适配，文档明确标记，不能冒充原图像全模型复现。
冻结96条VAL筛查：旧3个分类集+新增5个分类集，Mantis/summary两表示，alpha1六点0.01/0.1/0.5/1/2/10；一次固定基底/类序，确定性解析读出不伪造多个独立训练种子。保留全部基线结果，不依结果删强基线。FeCAM是分类基线，不改造成回归算法，也不改变TMoT同时覆盖分类/回归的研究目标。当前和其他方法仍不是同存储字节预算，记录实际字节供后续预算配平。

## v14：低秩局部联合矩机制筛查
每次到达的数据按输入特征局部分区，分类在类内分区，回归对输入分区后保留输入-目标联合矩。每分量保存n、均值、标准化空间秩16协方差因子及残余对角；对角方差由构造精确保留，整体非线性风险仍是近似。最大4分量，按当前样本数限制为min(K,max(1,n//16))；固定随机投影16维加20步Lloyd划分，仅使用当前训练输入。历史生成时类内按分量真实计数、类间均衡；回归按所有历史分量计数采样。

72条固定机制筛查：HAR/UWave/DailySports/Energy的Mantis，以及Beijing/Air Quality的summary，2种子×K=1/4×3个残差惩罚。基础ridge和其余网络/优化配置与v11/v12对应实验一致。K1为低秩近似消融，K4检验局部分布；小样本类两者可能退化为相同有效K，不算独立机制证据。与已有同配置全协方差Gaussian/真实ER对照，不增删正式7数据分母。分量数随到达次数增长，当前不声称固定字节记忆，也不声称该混合高斯思想本身原创。

数值测试覆盖低秩因子+对角残差重建边际方差、双峰非线性回归关系、类增长和回归执行。该合成测试用于发现实现缺陷和验证容量，不能代替真实数据泛化证据。
