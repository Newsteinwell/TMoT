# v60 固定表示上的解析分类基线

在PhonemeSpectra、LSST、Handwriting上，使用与v54/v57/v59相同的mantis/summary特征、StableSemanticBasis512、第一任务校准、seed42/order17、相同TRAIN/VAL划分。无TEST、无真实历史样本缓存。

显式比较原始投影坐标raw与逐样本L2单位化unit两个表示条件，以分离FeCAM的单位化与类别协方差读出的作用；不把unit/raw事后择优合成一个未经声明的方法。

每个条件共享累计类别统计，输出三类头：最近类均值NCM（欧氏距离，无超参）；共享类内协方差的SLDA（均匀类别先验，样本权重池化，无偏分母N-K，迹尺度单位阵收缩，收缩系数.001/.01/.1/.5/.9/1）；类平衡累计ridge（.001/.01/.1/1/10/100，偏置不罚）。12个共享统计作业、156条验证轨迹。SLDA中.1恢复此前实现的固定收缩率。

各方法在每个表示条件内按最终VAL选超参，同时报告阶段平均指标。保留所有结果。与FeCAM v59比较必须核对相同输入hash和任务顺序；ridge raw应与v45相同ridge和协议控制逐阶段一致。独立核查最终累计统计与已到达TRAIN直接计算一致、保存预测重算一致。近期TMoT仍为v54 task256，不重新挑换配置。

持久数组计数反映本次共享统计实现（包括完整类别二阶矩），并不是NCM/SLDA最小内存实现；不能据此宣称TMoT更省内存。当前实验只诊断分类头，整体研究仍覆盖回归。
