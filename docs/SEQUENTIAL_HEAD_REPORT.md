## 解释与边界

蒸馏在六个回归配置中均降低FT的最终RMSE，但最佳强度由开发VAL选择，不代表一个固定强度的普遍优势。Beijing+Mantis和Energy+Mantis优于ER10监督头，其他四个回归组合仍弱于该头；不能据此替代更强的累计ridge、FeCAM或因果参考基线。

分类蒸馏改善很小，FT和蒸馏都严重遗忘。旧类子空间softmax对所有旧logit加同一个常数不变，因此旧类KL不能约束旧类整体相对新类的分数偏移。这是损失的可辨识性缺口；当前结果与此机制相容，但尚不能将全部失败归因于它。下一轮应直接检查跨新旧类的分数校准与稳定统计锚，而非只增加旧类KL权重。

FT与蒸馏使用相同当前任务样本、epochs、batch和优化器更新步数；教师前向增加蒸馏计算。ER10每阶段额外抽取4096个历史代表，虽然epochs相同，但优化器步数更多，因此本轮与ER比较是统一架构/协议对照，不能称同计算预算因果消融。

无历史样本缓存，教师仅在当前TRAIN输入上产生目标。分类为LwF思想的单头类增长适配；回归是输出MSE蒸馏，非原版LwF。参数继承与教师不变已测试。方法来源：https://arxiv.org/abs/1606.09282 。

总体目标尚未完成；这些弱于FeCAM的对照不会取代强基线。分类和回归继续共同验证，不从这轮局部收益宣称一般时序持续学习的稳健优势。
