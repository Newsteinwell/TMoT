## 证据边界

- UWave的开发改善值得跨数据验证；HAR增益较小，DailySports仍弱于真实回放/线性基线，Energy未达到5%下降门槛。目标未完成。
- v10同epoch但实际更新数不等，不能冒充等计算预算对照；v11使用ER有放回采样补齐4096历史训练样本，并审计实际步数相同。
- 生成样本不是新增真实观测，不能将4096条视为独立统计证据。高斯矩风险近似，不是非线性风险精确恢复。
- ER缓冲区4MiB，Gaussian存类或到达批次的全协方差；尚不等字节预算。
- 候选架构已扩展到v12的7个新增数据、2表示、2种子，168条，仅VAL；基础参数来源已冻结于配置。官方TEST仍不读。
- 生成特征回放与协方差方法已有研究，见ROUND3_PROTOCOL.md的原始论文链接；当前模块不单独声称原创性。
