## 对梯度偏差诊断的回应

v35发现统计生成样本与真实风险梯度存在明显差距。本轮通过固定已学习函数、精确累计其二阶矩，避免了这一特定生成式近似；但性能没有因此自动达到强参考水平。由此应区分两个问题：历史风险的可计算准确性，与固定函数是否具有足够的任务相关表示能力。首阶段监督可能偏向初始类别或初始域，但当前结果尚不能证明这是唯一限制。

下一步方法设计需要同时处理函数学习的覆盖范围和历史风险可迁移性，而不是把“精确矩”或“梯度更接近”单独当作完成目标的证据。正式TEST继续封存；本轮单种子、单类序VAL选参仍只是开发证据，不能替代确认性多种子实验。
