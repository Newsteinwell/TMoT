# 累计矩驱动的证据读出候选

本候选检验“训练头与最终统计读出分离”的潜在问题。它是经验贝叶斯读出对照，不是WiMoT忠实复现，也不把ARD本身作为创新。[Tipping (2001), Sparse Bayesian Learning and the Relevance Vector Machine](https://www.jmlr.org/papers/v1/tipping01a.html)提供了相关经典背景；当前实现使用固定特征、共享多输出精度及高斯one-hot替代目标，并非该文分类RVM的完整复现。

对已到达样本的加权、中心化充分统计量S=X'WX，T=X'WY，V=tr(Y'WY)，设A=diag(alpha)+beta S。读出M=A^{-1} beta T。积分掉线性权重后，负对数边缘似然（略去与参数无关常数）为

L=1/2 [m(logdet A - sum log alpha - (n-1)log beta)+beta V-beta tr(T'M)]。

m为输出维数，截距以加权均值消去；输入与目标均值只来自已到达训练数据。回归W=I；分类每类总权重相同，权重归一使总和为n，因此它是加权高斯替代模型，并非类别概率似然或校准分类概率。类新增时重新构造已见类的one-hot交叉矩，不制造未见类别。

两种预声明变体：isotropic共享一个alpha；ard每特征一个alpha，所有输出共享。固定Adam lr0.1、60步，log alpha与log beta限制[-12,12]，记录初始/最终/最佳训练证据并保留最佳参数。每次到达从确定初始化重拟合全部已见统计，无未来或VAL标签，无原始历史样本。没有全局收敛保证；优化停滞、非有限或Cholesky失败必须报告。

这是统计读出的改动，仍不适配冻结编码器；它只检验一致读出与自适应正则化能否改进结果。不会据此宣称已解决全部表示适配问题。

验证：小样本稠密观测空间协方差的证据值与矩公式一致；梯度有限差分核验；类增长；多输出回归分阶段累计与一次累计预测一致。数学等价不能替代泛化效果验证。

## 有界优化复核

v25保持同一目标与参数边界，使用60步Adam作为确定性起点，然后用有界L-BFGS-B细化。停止依据训练目标与梯度，不依据VAL指标。边界处使用KKT投影梯度：下界且梯度为正、上界且梯度为负的坐标置零，其他保持。单独记录该范数是否≤1e-6，避免把相对目标停止当成小梯度收敛。各阶段Adam起点的证据必须与v24匹配，最终后验用独立CPU公式复核。
