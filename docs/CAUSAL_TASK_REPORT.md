## 解释

北京的主要差距来自输入/目标形式：TMoT无先验约44 RMSE，残差形式降至27.34（Mantis）和27.09（summary）。然而同形式Ridge分别已有27.70和27.13；TMoT只改善约1.28%和0.13%，远未达到相对强基线5%的明确增益标准。summary阶段平均还从Ridge28.57变为TMoT29.08，不能称全过程优势。

仅追加末值并不足以得到残差形式的效果：北京TMoT append为33.04/38.67，且弱于同输入Ridge30.71/33.68。目标残差化改变了训练函数、正则化作用与合成点学习；本轮不能把收益唯一归因于某一个环节。

Air的残差先验不适配：TMoT Mantis由none0.963变为1.150，summary由0.827变为0.971。append的summary最终0.8245只比none0.8265略好；既有warm ER10 summary最终约0.8073仍更强，不能只与较弱的ridge比较。

不存在一个已验证的统一默认先验；不能事后北京用residual、Air用none并声称通用框架。下一步若研究先验适配，应只依据已到达训练数据设计可固定的机制，并与同样拥有该机制的简单基线公平比较。一般时序回归未必有历史目标通道，因此原始无先验路径和类增长分类仍须保留。
