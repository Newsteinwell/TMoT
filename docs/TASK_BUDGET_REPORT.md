## 结论与原因

TMoT 在12个数据集×表示组合中，最终指标均优于本轮不带累计矩的 ER10；11/12优于带矩统计 ER10。Handwriting+Mantis 仍落后5.77个百分点。11/12不是11个独立数据集，也不是跨种子稳健结论。阶段平均指标还有四组弱于带矩统计ER10：Air+summary的平均RMSE高0.0292，Energy+mantis高0.3547，Energy+summary高1.1316，LSST+mantis的平均宏准确率低0.8406个百分点。因此最终指标的改善并不等于全过程优势。

大缓存基线确实解释了此前部分劣势，但不能解释全部：带矩统计的 ER10 相比不带矩版本明显改善多个任务，说明固定表示上的历史统计仍然重要；Handwriting 低样本下合成代表点可能更不稳定。当前数据只支持这些诊断方向，不构成合成点失效机制的因果证明。

本轮 ER10 沿用既有每阶段从头拟合函数网络的流水线，以隔离缓存/统计因素；它不是已经覆盖所有常用 warm-start ER 实现的强基线。不能仅靠这轮结果宣称战胜持续学习领域强基线。此前更强的线性/残差方法（例如 Beijing 上约27的验证RMSE）仍必须纳入后续比较。
