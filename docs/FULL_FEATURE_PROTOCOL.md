# v46：固定随机投影的表示损失诊断

v45新压力集仍无相对强对照的明确增益。预登记检验：保持冻结输入、首阶段归一化、样本权重、类别增长/回归时间顺序及六点ridge一致，比较512维投影和不丢坐标的完整表示。覆盖PhonemeSpectra、LSST、Handwriting，以及Energy、Beijing PM2.5、Air Quality；Mantis/summary两表示，两个坐标方式，六个ridge，共144条VAL轨迹，seed42/order17。TEST不参与。

完整坐标使用与StableSemanticBasis相同的首阶段semantic mean/RMS和amplitude逐维mean/SD。为避免仅因维数改变而大幅改变正则化尺度，semantic乘sqrt(448/原semantic维数)，amplitude乘sqrt(64/原amplitude维数)，保持随机投影的期望分支能量；不声称每个样本范数完全一致。512分支直接使用既有transform，不改实现。

每阶段仅使用已到达TRAIN样本，分类采用每类等权（每例权重1/(已见类数×该类已到达例数)），回归采用每例等权及同一首阶段目标标准化。保留所有已到达输入并重拟合加权ridge，偏置不惩罚；加权中心化后按min(N,D)选择原始或对偶求解，同一特征分解复用六个lambda。所有144条都用这一求解器，另核对已有512维控制预测。

这是具有无限历史访问的表示/读出诊断，不是新在线算法，也不是经验性能必定更高的数学上界。即使完整坐标更好，也仍须解决在线统计存储、计算量和迁移机制；不能将诊断结果当作TMoT性能。逐阶段保存预测和最终读出、记录使用的历史样本数与实际维度；避免保存重复大矩阵检查点。

预先报告六数据×两表示的最佳VAL最终指标、对应阶段平均、六点全结果，以及固定lambda配对结果。分类百分点和回归RMSE不合并平均。完整表示胜出只支持存在可利用的投影损失；不胜出也不证明表示完全充分，因为优化限于线性ridge。当前选择与所有负结果保留，正式十数据集验收集合不变。

执行采用12个并发特征组，每组最多2个CPU数值线程，共24线程匹配25 vCPU；这是解析线性求解，GPU占用不作为效率目标。同一组共用分解的耗时不能计为六次独立运行的耗时。
