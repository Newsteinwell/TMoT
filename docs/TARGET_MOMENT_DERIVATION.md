# 目标相关矩保护：精确量与近似量

设一个局部训练分量有n条记录，中心化输入和连续目标矩阵为X∈R^(n×d)、Y∈R^(n×p)，经验协方差分母为n。取Y的薄SVD：Y=USVᵀ，并只保留数值非零奇异值。定义

- Lx = XᵀU/√n；Ly = VS/√n；
- R = (I−UUᵀ)X；
- Q = AAᵀ + diag(v) 为RᵀR/n的低秩加对角近似，要求v非负，且diag(Q)=diag(RᵀR/n)。

对相互独立的标准正态向量z、u、ε，生成

x̃ = μx + Lx z + A u + diag(√v) ε，
ỹ = μy + Ly z。

生成**分布**满足：

Cov(x̃,ỹ) = Lx Lyᵀ = XᵀY/n；
Cov(ỹ) = Ly Lyᵀ = YᵀY/n；
diag Cov(x̃) = diag(XᵀX/n)。

最后一个等式使用UᵀR=0。目标常量或目标列线性相关时，仅保留Y的实际数值列空间，无需求逆奇异的目标协方差。代码相对奇异值阈值1e-12、绝对阈值1e-15，因子存float32，因此实现结果是数值容差内相等，不是无限精度等式。

每个分量保留原始计数和均值，混合权重取n_j/Σn_j。由全协方差公式，混合后的XY、YY和输入边际方差也保持对应全部已存经验记录的这些矩。所有参数只由已经到达的训练记录计算；目标仅用于生成训练回放，不要求推理时提供目标。

## 不成立的更强结论

完整输入协方差XX仍被近似。因此即使对任意线性预测器W，其历史平方风险也可能因tr(W ΔCov(XX) Wᵀ)而改变；不能把目标矩保护称为任意历史风险精确恢复。当前累计ridge捷径另存完整固定基底矩，保持其原始精确统计解。

非线性预测器依赖更高阶分布信息，本构造不保证其历史风险或测试误差。4096条有限生成样本还存在Monte Carlo波动；上述等式约束生成分布，而非保证每批生成样本逐元素满足经验矩。审计使用因子解析计算分布矩，不能用该审计代替预测性能验证。
