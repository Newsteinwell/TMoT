原版关键区别：后续域使用0.5 SupCon + L_hist，不再使用当前CE；当前原型后续仍使用CE。因此后续迁移需同时比较原损失与类新增所需的新类别监督，避免将差异误归因于读出。

缺失类别设计：不为不存在的(domain,class)生成均值或协方差。全类别DIL保留原版域混合；纯CIL至少需要跨任务类别的共同可比读出，不能仅在各任务内softmax后直接等权融合。后续必须用可比较的全局密度/全局方向或显式域门控进行验证。

回归保留输入-目标交叉矩与目标二阶矩。OSCL的离散类别方向不直接套入回归；共享表示、仿射传输和历史风险，读出采用回归目标相容的估计，并明确分支差异。
