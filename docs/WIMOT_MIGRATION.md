原版关键区别：后续域使用0.5 SupCon + L_hist，不再使用当前CE；新迁移实现仅在新增类别时加CE；已比较移除该CE的消融。

缺失类别设计：不为不存在的(domain,class)生成均值或协方差。全类别DIL保留原版域混合；纯CIL至少需要跨任务类别的共同可比读出，不能仅在各任务内softmax后直接等权融合。已用全局可比OSCL读出验证该扩展；不能宣称稀疏域条件门控已实现。

回归保留输入-目标交叉矩与目标二阶矩。OSCL的离散类别方向不直接套入回归；共享表示、仿射传输和历史风险，读出采用回归目标相容的估计，并明确分支差异。

通用入口：`tmot/dual_basis.py`、`tmot/transport_learner.py`、`tmot/experiment_transport.py`。全类别DIL保留原版域专家；CIL采用已观察类别合并矩的全局OSCL扩展，非原版稀疏域算法。回归共享表示及矩传输、使用回归岭读出。上游配置固定，第一阶段100、后续50 epochs。
