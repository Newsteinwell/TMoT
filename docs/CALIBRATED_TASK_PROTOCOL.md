# v69 首任务训练数据确定持久性先验强度

只在第一任务TRAIN上计算每个目标的带截距一元最小二乘斜率 beta=cov(past,target)/var(past)，将beta限制在[0,1]，输入无方差时取0。offset=beta*past；目标残差的均值另由第一任务TRAIN确定。beta从此冻结，不能随未来任务改变目标坐标，不访问VAL/TEST选择beta。边界0表示无持久性偏移、1表示v68固定残差形式；输入仍保留最后观测值。

这是首任务统计启发式，不是校准概率、不保证最优或泛化，也不能把已知线性回归/收缩本身作为原创贡献。对于无历史目标输入的一般回归仍需无先验路径，本轮不取代总体问题定义。

Beijing/Air × Mantis/summary × 固定残差/自定强度，共8个共享训练、96条轨迹（task256与ridge各六值网格）。固定残差完整复现v68。两方法使用相同beta、输入、目标缩放与ridge网格，30epochs，seed42，无历史真实样本缓存。报告beta及未截断值、最终/阶段平均RMSE、全部负结果。不按数据集事后决定是否启用该规则；旧append/none/warm ER10强对照继续保留。仅旧TRAIN/VAL机制验证，无TEST。
