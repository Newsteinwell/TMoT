## 结论

锐化相对soft在四个分类配置改善最终准确率，一个持平、一个退化；硬目标在五个改善、一个退化。LSST+Mantis的锐化改善13.342个百分点，Phoneme+Mantis硬目标改善13.876个百分点。教师argmax、支持输入和更新步数没有变化，因此这是目标形式对当前训练流程的影响，而不是新增教师判别信息。

本轮最佳结果在六个配置仍全部低于既有强读出。Handwriting+Mantis硬目标40.385%虽高于固定FeCAM 36.538%，但其阶段平均32.822%低于教师36.026%，且低于既有ridge最终51.923%；不能称稳健胜出。其余五个配置即使择优也低于固定教师。

v75和v77共同表明历史覆盖与软目标平缓都是可改善环节，但没有证明学习模型能够超越强统计读出。保持统计教师的直接推断能力，后续优先验证新增表示/统计信息是否形成互补，而不是继续把一个弱于强基线的模仿模型作为默认预测器。本轮模块不升级为默认TMoT；一般多维时序持续学习目标与分类、回归共同验收要求保持不变。
