# v68 当前TMoT的因果参考对照

在Beijing PM2.5和Air Quality、Mantis和summary上，固定seed42、五个时间域及既有TRAIN/VAL，比较三种输入/目标形式：none原输入；append追加窗口最后一个目标通道观测；residual在append输入基础上预测相对该观测的残差。原始窗口通道0的含义沿用经核验的v19数据构造，原始数据SHA与特征ID/标签逐项检查。缩放仅使用第一任务TRAIN，VAL偏移只取可观测输入末值，不取未来目标。

每组共同输入分别交给当前task256 TMoT和累计ridge，所有方法相同六值ridge网格(.001,.01,.1,1,10,100)。12组共享训练、144条完整回归轨迹；同一模型六个解析读出，避免六次重复训练。30 epochs、固定合成点容量，无历史真实样本缓存，不访问TEST。所有ridge基线逐阶段精确复现v19，none TMoT逐阶段精确复现v54。保持所有正负结果。

原始目标的第一任务标准差用于三种形式；残差均值仅用第一任务TRAIN。特征末值追加标准化仅用第一任务TRAIN，与v19一致。此对照用于区分输入信息和目标形式的作用，不声称两者之外所有优化条件完全不变。残差目标也会改变合成点学习。

报告最终RMSE与阶段平均RMSE，既有warm ER10和持久性基线继续保留。当前是旧开发数据上的机制验证，不是多种子稳健性或独立盲测。持久性先验只适用于输入包含历史目标的预测场景，不把它称为任意时序回归问题的必需条件；总体框架仍需支持无该先验的普通连续标签回归和类增长分类。
