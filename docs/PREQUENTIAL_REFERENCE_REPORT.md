## 结论

北京的训练前误差加权优于等权融合：TMoT Mantis由32.576降至31.311，summary由34.231降至31.354。但这仍明显弱于单残差专家27.342/27.092，以及同先验Ridge27.695/27.127。不能用相对等权融合的改善代替相对强基线的优势。

Air的两种融合接近：TMoT误差加权为0.9997/0.8436，等权为0.9998/0.8448；两者仍弱于旧最佳单TMoT0.9626/0.8245。误差加权不是本轮普遍收益来源。summary的warm ER10约0.8073也继续保留为强参考。

误差倒数给多个分支保留权重，因此可能削弱优秀专家；但该结果不能证明简单硬选择一定有效，训练前累计误差也可能与训练后的历史域评估目标不一致。后续若区分选择规则与信号本身，应在相同已保存预测上预先固定规则，不用VAL标签挑选专家；不继续扩大这条未超过强基线的软融合方案。

当前没有达到多数数据集稳健优势。所有失败配置保留，不更换默认算法。分类局部增益与回归失效分别报告，总体问题仍是一般多维时间序列持续学习。
