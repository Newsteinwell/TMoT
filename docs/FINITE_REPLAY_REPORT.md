# 有限回放批矩校准结果

36条VAL实验完成，34项测试通过；36对v15/v16的基础读出、基底、优化次数及验证ID/标签一致。校准历史样本数逐阶段匹配此前到达数量，未使用当前批目标或验证标签。

## 实际批次审计

校准发生的阶段共144个。实际生成训练批的最大相对误差：
- after_cross_error: 6.601e-09
- after_target_cov_error: 4.343e-09
- after_input_variance_error: 2.422e-09

这次审计对象是实际有限批，不只是解析生成分布；完整XX、高阶关系和非线性风险仍未保证。

## 下一步机制方向

校准不能恢复未存储的更高阶分布关系。独立于真实回放偏好，仍可检验WiMoT统计门控与局部专家的直接连续目标读出：直接计算局部联合统计的条件预测，避免用有限伪样本间接拟合神经残差。需先核对既有混合回归方法和官方WiMoT门控实现，预先锁定对照，不把已有统计方法本身包装成原创贡献。真实回放偏好仍待用户答复，未据默认选项假定批准最终混合设计。
