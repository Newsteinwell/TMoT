# v80：残差冷启动/暖启动配对实验

## Material Passport

- 状态：运行前固定；代码实验。
- 依据：v79 的24个local配置全部降低TRAIN误差，只有7个降低同输入base的最终VAL误差。
- 数据：原有TRAIN/VAL开发划分；不读取TEST，不作为独立确认。

唯一改变：每阶段残差网络从零输出重新训练，而不是运输上一阶段网络。
解析累计统计、local历史统计和ER10缓存均保留，不把冷启动误称为丢弃历史。
两数据×两表示×三参考×两回放×两惩罚，共48个冷启动配置，与v79逐一配对。
所有超参数、抽样种子、训练轮数和步数均不变；运行12路并发，预计新增磁盘约0.85GiB。

核验：首阶段全预测逐元素等于v79；每阶段解析预测、标签、样本ID、ER抽样索引、
历史支持数量与优化步数均一致；最终模型按原设备和分批精确重现预测。
分析同时报告最终RMSE、平均阶段RMSE、TRAIN诊断以及对既有强基线的差距。
冷启动改善只能说明这一初始化选择影响结果，不能自动证明解析分支漂移是唯一原因，
更不能替代类别新增和跨数据集多种子总体检验。全部失败配置保留。
