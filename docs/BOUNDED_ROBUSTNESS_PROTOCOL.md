# v64 固定参数复验

覆盖Handwriting、LSST、PhonemeSpectra × Mantis/summary × seed42/43/44 × order17/23，共36次共享训练、180条完整分类轨迹。12并发。seed42/order17作为已知开发控制单列；其余组合此前用于v55开发，因此本轮是固定参数重复性检验，不是独立盲测。只用TRAIN/VAL，不访问TEST。

五个头：原TMoT、complete、bounded、FeCAM、原始累计ridge。各数据集/表示的超参数全部从既有seed42/order17报告读取冻结，不在新种子/顺序重新选参。任务网络仍使用同一任务256合成点与30 epochs。原TMoT逐阶段预测及最终g/k、网络、合成点和RNG必须精确复现v55；开发控制的complete/bounded/FeCAM预测逐阶段必须精确复现v63/v59。

不保存重复的大模型；以SHA引用v55精确相同的最终模型，只额外保存新单位化统计，用于后续独立核验。预测、阶段指标、配置和失败日志全部保留。单独报告最终和阶段平均，与FeCAM及ridge分别成对比较，不事后按种子挑选头。六个数据集×表示组合不能当作六个独立数据集。

本轮检验类别条件统计读出的重复性，未覆盖回归；一般多维时序持续学习目标及回归强基线保持不变。FeCAM借鉴的是类别条件几何，单纯移植已有距离分类器不作为TMoT的原创贡献。
