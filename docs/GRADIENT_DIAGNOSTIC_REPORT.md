# v35：统计重放的风险梯度偏差

36个固定最终模型、1440组比较全部完成并通过审计。训练数据和检查点散列与记录一致；模型参数保持不变；两种分块计算的完整经验梯度通过一致性检查；余弦、范数、内积及相对误差的代数关系逐项核验通过。测试先完成69项全套检查，随后新增类别重复加权测试并重跑3项梯度测试，均通过。源码4ff5191。

只读取已到达训练数据。没有读取VAL/TEST，没有训练更新或新模型检查点。模型来自v31高斯与ER暖启动，各覆盖九组数据/表示、两种损失；每种近似在4096/16384样本下各重复5次。

## 主要结果

下表先对每个固定模型的5次抽样取中位数，再对36个模型取中位数；不把1440次抽样视为1440个独立数据集。误差为‖g近似−g真实‖/‖g真实‖。

| 近似方式 | 4096：余弦 / 相对误差 | 16384：余弦 / 相对误差 | 16384反向抽样数 |
|---|---:|---:|---:|
| 真实数据经验抽样 | 0.9967 / 0.0940 | 0.9990 / 0.0507 | 0/180 |
| ER缓冲区抽样 | 0.9969 / 0.0803 | 0.9990 / 0.0456 | 0/180 |
| 单高斯统计重放 | 0.4641 / 1.4889 | 0.5052 / 1.4809 | 12/180 |
| 合并小簇的局部统计 | 0.6676 / 0.9422 | 0.6944 / 0.8809 | 3/180 |

“反向”指沿负近似梯度的真实经验风险一阶方向导数为正，不表示实际有限步长或Adam更新一定使风险上升。经验抽样扩大4倍后误差约减半，符合采样波动减少的现象；高斯误差几乎不变，支持存在明显分布近似偏差。局部统计较高斯改善，但未接近经验抽样水平。

两种模型来源均存在差距。16384样本时，ER模型上的高斯余弦/相对误差中位数为0.378/3.141，局部统计为0.469/2.237；高斯模型上分别为0.625/0.856和0.822/0.601。因此结果并非只在ER模型上观察到，但偏差幅度明显依赖模型所处位置。

## 对方法设计的含义与边界

证据支持：二阶统计重放可以保留线性二次风险所需信息，却仍显著改变可学习非线性分支的风险梯度；单纯增加同一拟合分布的样本量不足以消除这项偏差。下一步优先检验能否在数据到达时保存额外的任务相关函数信息，用于约束或校正后续风险近似，同时控制存储量和模型漂移带来的失效。

不能从本实验声称已证明整个训练过程的唯一失败原因。这里测的是最终固定模型上的全部已到达训练风险，包含残差惩罚，不是每阶段更新前的旧任务风险；模型来源、优化位置和损失类型都会影响梯度。梯度更接近不等于泛化更好，更不能算作新增的VAL/TEST性能胜利。

正式七数据集分母、分类与回归扩展及最强参考保持不变。多数数据集明确且稳健的性能优势仍未实现，目标保持进行中。
