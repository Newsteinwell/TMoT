## 结论与解释

局部矩方法在Mantis下：Handwriting虽然比ER高3.846个百分点，但与ridge持平，不能称相对最强基线胜出；LSST比ridge高0.895、却比ER低0.343个百分点，且阶段平均69.986%低于ridge71.902%；PhonemeSpectra与ridge最终持平、比ER低1.056个百分点。三数据集均未达到相对本轮最强对照至少+1个百分点的明确增益标准。

无预训练summary下，局部矩方法优于线性ridge，但Handwriting/LSST仍落后ER；PhonemeSpectra仅比ER高0.452个百分点，未达阈值，且阶段平均17.303%低于ER18.059%。因此新增难度没有自动转化成方法优势。Handwriting的VAL只有28例，许多类仅1例，宏指标跳变很粗，单次差异尤其不能当稳健证据。

跨表示差距明显，说明输入表示质量仍是主要影响因素之一，但这里比较的是整个表示管线，不能把差异单独归因于预训练。局部矩相对弱表示ridge的收益说明学习非线性函数能提供补充；多数情况下仍弱于同网络ER，与历史生成分布不能充分保存非线性判别结构的解释相容。它不是该因果机制的单独证明。

下一轮优先隔离两个问题：固定512维投影相对完整冻结特征是否丢失可利用判别信息；以及在同表示/同优化下，历史样本近似造成的风险偏差。必要时用明确标为离线诊断的完整TRAIN线性读出上界判断表示瓶颈，不能把保存全部训练数据的诊断冒充在线方法。回归分支继续保留，不用新增分类结果替代一般任务目标。
