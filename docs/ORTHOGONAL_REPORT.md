## 可定位的失败机制

最终TRAIN矩显示，Air Quality的120个训练样本对应输入矩秩120；目标条件残差迹接近浮点零，两个表示的修正权重范数均低于1e−12。Articulary、RacketSports也接近这一情况，NATOPS与Epilepsy的目标残差迹接近零。对于这些高维、小样本训练集，严格正交化基本消除了新增函数与目标的残余相关，因而退回原线性模型。这是对当前训练矩的诊断，不等价于表示对未见数据已经充分，也不是泛化能力保证。

Beijing仍有非零目标残差，但ER/summary的早期阶段出现巨大误差：ridge=.001的第二阶段RMSE达到6323.746，最终41.134、阶段平均1372.829。只看最终指标会掩盖失稳。三个ER/summary配置（ridge=.001/.01/.1）在等价的变换坐标稠密求解下超出预定rtol=1e−6、atol=2e−7的权重一致性容差，最大绝对差5.87e−5；没有放宽容差。最大正交残差3.48e−7，残差PSD数值修正1.71e−9。

因此需要区分两件事：近乎插值的原坐标把创新信号消掉；伪逆残差化又可能放大弱方向的外推。数值复算差异和早期验证崩溃同时出现，但本轮没有证明前者单独造成后者。下一步如继续此路线，应采用有界的正则化投影，并针对近奇异训练矩和分布外输入测试，而非继续裸伪逆正交化。
