# v56 原训练不变的逐阶段代表有效性诊断

v55稳健性复核未支持task256相对更强ER的整体优势。本轮重放v54的task256/seed42/order17，全部六数据集两表示；不改变训练、代表或任何决策。每阶段训练完成后，由独立诊断对象重建已经到达的TRAIN分区，保存其真实行仅供离线检查，不注入learner。

对每个已到达分量，在同一个当前网络下比较原始256点Gaussian初始化与优化后代表：当前网络特征均值/Gram相对误差及原匹配目标。每分量出生阶段必须复现其优化日志目标；后续按age记录比值及风险权重。分类按类平衡，回归按样本数加权。只用已到达前缀；TEST不读取。每个分量出生时的低目标能否延续到后续函数，是待检验假设，不能从这个诊断直接推断验证精度因果关系。

72条六点读出轨迹逐阶段预测精确复现v54；最终网络、G/K、代表和主RNG也应一致。结果引用现有共享检查点，不复制大模型。诊断对象真实历史访问只用于度量，明确不属于候选记忆。输出按数据集/表示/阶段/分量年龄，不把不同年龄的跨数据差异误认作独立因果效应。
