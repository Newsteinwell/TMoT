## 判断

该规则缓解Air固定beta=1的错误先验，但未形成统一改进。Air+Mantis TMoT从固定残差1.150降为1.010，仍弱于旧none0.963；Air+summary从0.971降为0.828，仍未超过旧append0.824及warm ER10约0.807。不能只以较差的固定残差为参照宣称优势。

北京TMoT的最终RMSE从固定残差27.342/27.092退化为29.591/29.756，阶段平均也退化。首任务经验相关性不足以决定后续时间域的最佳残差先验，且最佳先验不只由目标与末值的相关性决定，还受到模型容量、正则化和分布变化影响。

TMoT相对同先验Ridge同样未形成一致优势：北京Mantis最终略差，summary仅略好；Air summary最终较好但阶段平均较差。不能将共享先验的收益计入TMoT独有贡献，也不把本规则升级为默认方法。

下一步若研究时间变化的可靠性，应保证历史统计的坐标一致性。例如使用只由已到达训练数据形成的预测误差信号，需要先明确训练前后时序与历史专家可访问范围；不能直接用VAL挑选先验，也不能改变beta后继续把旧残差统计当成同一目标。分类与普通连续标签回归目标仍须保留。

## 核验

所有固定残差轨迹逐阶段精确复现v68；独立用带截距最小二乘重算beta并核对截断，校验首任务训练数量、首任务缩放、原始/特征哈希、所有阶段样本身份与RMSE、最终检查点预测。历史目标只取输入窗口最后可观测值。未将训练标签之外的数据传入beta拟合。
