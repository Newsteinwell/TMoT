# v70 训练前误差加权：固定先验专家

每个方法保持none/append/residual三个固定坐标专家，不再修改历史目标坐标。第一任务无历史预测误差，三者等权。第t>=2个任务到达时，所有专家先使用t-1状态预测该任务TRAIN，累计各专家的平方误差；之后才训练本任务，再评估VAL。以累计MSE的倒数归一化加权（各专家样本数相同，等价于累计SSE倒数）；若有零误差专家，在这些专家间等权。无温度、遗忘率或阈值超参，不用VAL目标更新权重。此规则是常见误差加权启发式，不声称原创或理论优势。

TMoT和ridge使用完全相同的过程，各用自己的训练前误差。另设三专家始终等权的对照，区分融合本身与误差信号的作用。每个专家六个ridge值，同一融合配置的三个专家使用相同ridge；六值网格按旧开发VAL选择。两数据×两表示×两方法×两融合规则×六ridge=96条完整轨迹，4并发组、12个神经分支训练。

全部专家每阶段预测必须精确复现v68。保存训练前预测及当前任务ID/标签，只作离线审计，不供模型回放；在线权重状态仅三个SSE与计数，不保留样本。VAL预测、权重、指标全部保留。各分支约3倍训练和存储成本，不能冒称与单模型等算力/等内存。相同专家数的ridge与等权融合为主要控制。

仅旧TRAIN/VAL、seed42，无TEST。权重更新使用的当前任务训练标签合法已到达，但需保持预测先于训练的时序。累计误差信号可能偏重长任务，不能声称解决了任意漂移。分类与一般无历史目标的回归仍在总体目标内，本轮仅研究具有历史目标输入的预测条件。
