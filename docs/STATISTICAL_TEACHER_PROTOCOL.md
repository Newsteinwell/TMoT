# v74 全部已见输出的稳定统计教师

上一轮旧类子空间蒸馏对所有旧logit共同平移不敏感，不能约束新旧类总概率质量。本轮检验：当前任务输入上的全类别统计教师，能否缓解该缺口。它仍不能保证在未观测旧输入上的保持；不得因目标函数消除一种不变性就宣称遗忘已解决。

分类教师：固定512维基底、FeCAM alpha1=10（所有数据统一，不在本轮选择）。先用当前TRAIN更新类别统计，再在同一当前TRAIN上生成全部已见类目标。d为每类距离，p=softmax(-d/mean_class(d))。尺度下限1e-12，零距离全平局为均匀分布。该概率仅作蒸馏目标，不宣称已校准后验。学生所有已见类CE + lambda KL(p_teacher || p_student)，温度1；类别次序核对一致。新旧类整体偏移会改变本轮KL。

回归教师：同样稳定基底与首任务目标标准化，累计ridge固定0.1；学生当前MSE + lambda对教师输出的MSE。教师参数不是本轮最优强基线，必须报告教师本身与学生，不将模仿收益视为超越教师。

固定lambda=0/.1/1/10，6个既有开发数据×2表示，48轨迹，seed42/order17。网络、warm初始化、30epochs、优化器同v73。无历史原始样本缓存；教师持久统计内存按实际方法存在，不能称零内存。教师当前TRAIN输出为审计产物，不作为以后任务训练缓存。每阶段保存VAL教师/学生预测。只存学生最终模型和基底，教师可从到达序列重建，不将磁盘省略等同于算法不持有教师。

lambda=0完整轨迹应精确复现v73 FT；同一数据/表示所有lambda教师输出应一致；独立重算指标及最终学生检查点。分类教师与v59固定alpha10逐阶段对照。回归重建累计正规方程检查教师。无TEST。本轮是稳定统计约束机制验证，不能替代TMoT对更强选参FeCAM/ridge的比较。
